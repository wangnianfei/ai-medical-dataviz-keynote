## 二、科研配色与视觉美学权威项目及书目

| 项目 / 论文 / 书目 | 链接 | 核心价值 |
| :--- | :--- | :--- |
| **Crameri et al., *Nature Communications* (2020)** | https://doi.org/10.1038/s41467-020-19160-7 | *"The misuse of colour in science communication"* —— 反彩虹色（Rainbow/Jet）的科学铁证 |
| **Scientific Colour Maps (`scico` / `cmcrameri`)** | https://www.fabiocrameri.ch/colourmaps/ | 感知均匀、色盲友好、黑白打印不失真的科学色图标准 |

| **MetBrewer**（Blake Robert Mills） | https://github.com/BlakeRMills/MetBrewer | 取色自纽约大都会艺术博物馆传世名画，兼顾艺术品位与色盲安全 |
| **paletteer** / **PyPalettes** | https://github.com/EmilHvitfeldt/paletteer<br>https://github.com/y-sunflower/pypalettes | R / Python 聚合配色枢纽，统一语法调用 2,500+ 套专业色板 |

| **ColorBrewer 2.0** | https://colorbrewer2.org/ | Cynthia Brewer 打造的分类/顺序/发散经典配色工具 |
| ***Fundamentals of Data Visualization***（Claus O. Wilke） | https://clauswilke.com/dataviz/ | 科研数据可视化美学圣经（在线免费版），以 Ugly / Bad / Wrong / Good 对照教学 |

| **日本传统色彩体系 & Pantone / CIE 色彩标准** | https://www.pantone.com/ | 《配色设计原理》《日本传统色》及工业级色彩体系参考 |
