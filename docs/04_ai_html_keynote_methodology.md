## 一、为什么逐渐放弃 PowerPoint，转向 Slides-as-Code（HTML 幻灯片）？

传统 `.pptx` 在 AI 时代暴露出四大结构性短板：

1. **二进制黑盒，难以与 AI 协同迭代**：AI 改一段 HTML/CSS 只需 3 秒且能做精准 `git diff`；改二进制 `.pptx` 极易错位、丢字体、破坏母版。
2. **静态死板，讲不清动态机制**：面对“文字接龙”、“`/compact` 上下文压缩”、“子代理与 KV Cache 显存溢出”、“RAG 滚动溯源”、“R 代码实跑出图”、“红绿色盲实时模拟”这类机制，静态截图远不如浏览器里**一点就动的真实交互组件**。
3. **跨设备排版灾难**：换一台投影仪电脑，字体缺失、公式偏移、右侧被切掉几乎成了学术会议常态。
4. **数据、代码与幻灯片割裂**：图表改了一个统计口径，又要重新导出 PNG 再手动拖回 PPT。

**HTML5 + CSS3 + Vanilla JS（零外部依赖单页工程）** 完美解决上述全部问题：
- 打开任意浏览器即可**断网离线放映**；
- `Cmd+P` 秒导 16:9 静态 PDF 兜底；
- `git push` 开启 GitHub Pages，听众扫码即可在手机/电脑上**亲手把玩每一页互动演示并复现全部 R 代码**。

## 二、AI 做 HTML 幻灯片的六步工程化方法学

这套方法学完全沉淀自本次 38 页医学科研演讲稿从 v1 到 v7 的真实打磨历程，并已封装为可复用的开源 Agent Skill（[`ai-html-keynote`](../skills/ai-html-keynote/SKILL.md)）。

### 第一步：建立统一 Git 仓库骨架（数据、代码、图、幻灯片四位一体）

把每一次重要演讲当作一个小型软件工程项目来管理：
- `data/`：存放全部脱敏 CSV 教学数据；
- `code/r/`（或 `python/`）：用固定随机种子与统一主题脚本（`00_theme_pub.R`）一键生成 300 DPI PNG + 矢量 PDF；
- `assets/`：分类管理生成图、原版英文顶刊图、人物素材；
- `slides/`：`index.html` + `styles.css` + `deck.js` 三文件闭环；
- `docs/`：大纲、链接、素材溯源清单与方法学文档。

### 第二步：用“硬约束”锁死版式与字号，杜绝 AI 审美跑偏

对 AI 说“做漂亮一点”是 0 阶提示词；真正出彩靠的是写进 Skill 与 CSS 变量里的**量化审美红线**：

| 维度 | 硬性工程约束 | 解决什么痛点 |
| :--- | :--- | :--- |
| **16:9 画布锁定** | 固定 `1440 × 810` 逻辑画布 + Flex 居中 + `scale(min(vw/1440, vh/810))` | 彻底消除右侧被截断与不同分辨率投影仪错行 |
| **字号底线** | **全场可视文字 `≥ 16pt`（`22px`）**，涵盖标签、按钮、表格、SVG 标注 | 彻底消灭大屏后排“蚂蚁字”；放不下就删字或沉入讲稿抽屉（按 `N`） |
| **去蓝底、立暖调** | 暖白纸底 `#F7F4EE` + 纯白卡片 `#FFFFFF` + 暖黑曜石 `#1B1815` + 森林松绿 `#1B5E55` + 陶土红 `#C2412D` + 琥珀金 `#B07219` | 告别千篇一律的“企业 PPT 蓝”，建立医学编辑部杂志级高级感 |
| **封面不放方框图** | 封面仅在周边以圆形/切片/异形构图点缀科研可视化元素，绝不遮挡主标题 | 既有学科视觉辨识度，又保持高雅呼吸感 |
| **大屏短语 + 讲稿分离** | 每页文字 ≤ 6–7 行，视觉占比 60–75%；完整口播词写入 `data-notes` | 听众看图抓重点，讲者按 `N` 看提示词不卡壳 |

### 第三步：双轨视觉资产生产（代码出数据图 × 生成式 AI 出概念图）

坚决拒绝模糊网图和“全页纯文字白板”：
- **轨道 A（数据实证图）**：凡涉及统计对比、曲线、热图、生存分析，一律用 **R / Python 真实脚本**或本地 **MCP 顶刊图库（PlotCase / 顶刊美图社）** 调取原版高清英文图，**绝不强行机翻破坏原图质感**。
- **轨道 B（抽象概念图）**：凡涉及硬件形态（Agent 迷你小键盘、未来科研写文章专机）、底层机制（NSCLC 通路、SynthID 隐形水印）或警示画面（1cm=12格假尺子与“虾滑”肿瘤），直接用结构化英文/中文视觉提示词交由图像生成模型（如 Gemini）按统一暖白/黑曜石色温定制，并逐张验收重绘直到精确无误。

### 第四步：把抽象概念升级为“可点、会动”的交互与微动画

HTML 幻灯片最震撼现场观众的武器，是零外部依赖的原生态交互：
1. **黑客帝国式“真代码翻滚 → 实时出图”演播厅**：点击按钮，黑曜石终端里逐行滚动真实 R 代码，跑完瞬间亮出高清顶刊图。
2. **现场点击提示徽章**：每页互动页顶部放置 `≥ 22px` 的暖金/陶土红脉冲按钮提醒（`▶ 现场点击互动演示`），让讲者在台上绝不会忘记演示。
3. **纯 CSS/SVG 微动画具象化**：如 P16 的“人沦为网页 Chatbot 与本地报错软件之间的复制粘贴搬运工”循环动画、P34 的“AI 写 → AI 审 → AI 读”虚线流动闭环图。
4. **讲者工具栏内置**：键盘翻页、`#1..#N` URL 同步、`G` 全景网格、`N` 讲稿与计时器、`F` 全屏、任意图片点击灯箱放大。

### 第五步：双闸门质量验收（静态脚本审计 + 无头浏览器截屏肉眼巡检）

**绝不盲信“代码写完了就没问题”！** 每次修改后必须连过两道门：
1. **静态自动审计（`audit_deck.py` + `node --check`）**：自动扫描所有 `<img>` 路径是否存在、`font-size < 21px` 违规项、硬编码本机路径与 JS 语法错误。
2. **Headless Chrome `1280×720` 实机截屏巡检（`capture_slides.sh`）**：按 `#<N>` 精准渲染出每一张改动页的 PNG，由 AI 与人类逐张肉眼检查：
   - 是否存在单字孤行换行（如句末落单的 `子！`）？
   - 是否存在“头重脚轻”的下方大面积空白？
   - 圆形徽章或放大镜红圈是否被 `object-fit: cover` 裁边（应改 `contain`）？
   - 动画在 `t = 0` 首帧（及 PDF 导出时）是否依然清晰可见？

### 第六步：沉淀为开源 Skill + GitHub Pages 一键发布

将上述全部规范、排坑经验与审计脚本固化为标准 Agent Skill（`skills/ai-html-keynote/`）：
- **对自己**：装入本地 `~/.gemini/config/skills/`，以后做任何新演讲只需一句话调用，直接复用整套美学与 QA 体系，彻底告别 PowerPoint。
- **对社区**：连同数据、R 脚本、精选图库、HTML 成品与 Skill 一起托管到 GitHub 并开启 GitHub Pages，践行科研与知识分享的**开源复利**。
